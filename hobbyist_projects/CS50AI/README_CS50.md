# homework — CS50 AI problem sets

Coursework from **CS50’s Introduction to Artificial Intelligence with Python**.  
Each folder is a self-contained problem set; all unit tests provided by the course were passed.

## Layout

```text
homework/
├── search/                        # uninformed & informed search
├── minesweeper(knowledge_based)/  # propositional logic / knowledge base
├── crossword(constraint_satisfaction)/
├── nim(q_learning)/               # reinforcement learning
├── probabilistic/                 # uncertainty / Bayesian ideas
└── deep learning/                 # neural-net exercises from the course
```



## Topics covered

| Folder | Ideas |
|--------|--------|
| **search** | BFS, DFS, greedy best-first, A*; frontiers, heuristics |
| **minesweeper** | Knowledge-based agent; propositional sentences, inference |
| **crossword** | Constraint satisfaction; backtracking, arc consistency |
| **nim** | Q-learning; episodic RL, exploration vs exploitation |
| **probabilistic** | Probability, Bayesian networks / inference (course modules) |
| **deep learning** | Training loops, loss, basic architectures as assigned |


## Notes

- These are **course assignments**, not open-ended research. They demonstrate correct implementation of standard AI algorithms under automated tests.
- No proprietary or non-course data is included.
- Useful as a compact reference for classical AI building blocks next to the larger experimental projects in this portfolio.
